# Política de seguridad

## Versiones con soporte
El proyecto está en desarrollo. Solo la rama `main` recibe correcciones.

## Cómo reportar una vulnerabilidad
**No abras un issue público.** Usa el reporte privado de GitHub:
pestaña **Security → Report a vulnerability** de este repositorio.

Incluye, si puedes: versión o commit, pasos para reproducir, impacto y una propuesta de corrección.
Intentaré responder en un plazo de 7 días.

## Alcance
- El código de este repositorio y los APK publicados en sus Releases.
- Fuera de alcance: servicios de terceros (YouTube, Google). No pruebes contra ellos.
